  • CtrlShiftR Restart
  • CtrlShift. Skip
  • CtrlShiftB Re-brief
  • CtrlShiftM Brief ↔ verbatim

Install

About five minutes on macOS. Free speech works with no API key. Cloud voice is optional.

1. Plugin

Marketplace (easiest, not yet listed): once it appears in Grok’s Plugins / Marketplace, install focus-audio → Trust → start a new session. Until then, use GitHub below.

Or from GitHub:

git clone https://github.com/vbusnita/focus-audio.git
cd focus-audio
chmod +x bin/focus-audio
grok plugin install . --trust

2. Verify (free path)

focus-audio doctor
echo "Hello from Focus Audio." | focus-audio speak -

Doctor should report free macOS speech. No smart brief on this path — you hear cleaned verbatim (default).

3. Optional: cloud voice + smart brief

  1. Sign in or create an account at console.x.ai
  2. Add credits if needed
  3. Create an API key and copy it once
  4. Store it: security add-generic-password -a "$USER" -s "xai-api-key" -w "…"
  5. Opt in: focus-audio config --tts-provider xai --mode brief

Grok Build login alone is not enough for the cloud path — you need a Console API key for text-to-speech.

Full privacy notes and troubleshooting: README install guide →

Free on your Mac. Cloud only if you opt in.

Default speech stays on-device via macOS say. Only if you set tts_provider = "xai" do speech and smart brief rewrite call xAI with your key. Focus Audio does not ship a shared key or send analytics to the author.
